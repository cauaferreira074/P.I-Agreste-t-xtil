# 🧵 Agreste Têxtil

> Sistema de gerenciamento de pedidos e produção para o setor têxtil.

O **Agreste Têxtil** é um projeto desenvolvido com o objetivo de auxiliar no gerenciamento e acompanhamento dos processos de uma empresa do setor têxtil.

A proposta é centralizar informações relacionadas a **pedidos, produção, logística e relatórios**, proporcionando uma visualização mais organizada das etapas dos pedidos e facilitando o acompanhamento das atividades.

---

## 📌 Sobre o projeto

O Agreste Têxtil foi desenvolvido como parte de um **Projeto Integrador (PI)**, buscando aplicar na prática conhecimentos relacionados ao desenvolvimento de sistemas, organização de informações, interface de usuário e gerenciamento de processos.

O sistema foi pensado para representar o fluxo de um pedido dentro de uma empresa têxtil, desde o seu recebimento até a conclusão e envio.

### 🎯 Objetivos

- Organizar os pedidos recebidos pela empresa;
- Acompanhar o andamento da produção;
- Facilitar a visualização do status dos pedidos;
- Organizar informações relacionadas à logística;
- Apresentar indicadores e informações por meio de um dashboard;
- Melhorar a visualização das etapas do processo produtivo;
- Criar uma interface simples e intuitiva para os usuários.

---

## ⚙️ Funcionalidades

### 📊 Dashboard

O dashboard apresenta uma visão geral das principais informações do sistema.

Entre os indicadores apresentados estão:

- Pedidos recebidos;
- Pedidos em produção;
- Pedidos prontos;
- Pedidos atrasados;
- Estoque baixo.

A página também apresenta informações resumidas para facilitar o acompanhamento das atividades.

---

### 📦 Pedidos

A área de pedidos permite visualizar e organizar os pedidos recebidos pelas lojas/clientes.

As informações podem incluir:

- Número do pedido;
- Loja;
- Quantidade de peças;
- Data;
- Status;
- Informações relacionadas à produção.

A interface também conta com uma área de pesquisa e a possibilidade de criação de novos pedidos.

---
